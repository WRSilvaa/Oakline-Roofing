# Oakline Roofing

A responsive, single-page roofing business website built using HTML, CSS, and vanilla JavaScript.

**Live Demo:** https://wrsilvaa.github.io/Oakline-Roofing/

## About the Project

Oakline Roofing is a fictional roofing business website developed as a frontend portfolio project.

The goal was to create a professional, accessible, and responsive website that allows visitors to explore roofing services and submit enquiries.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Semantic HTML5 structure
- Accessible navigation and labelled form fields
- Services and project showcase sections
- Contact form with client-side validation
- Formspree integration for handling enquiries
- User-visible submission feedback
- Deployment through GitHub Pages

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Git and GitHub
- Formspree
- GitHub Pages

## What I Learned

This project helped me strengthen my understanding of semantic HTML, responsive CSS, DOM manipulation, event handling, form validation, asynchronous JavaScript, and deploying a static website.

I also gained practical experience debugging code and managing a project using Git.

## Disclaimer

Oakline Roofing is a fictional business created for educational and portfolio purposes. Project imagery is illustrative and does not represent verified work completed by a real roofing company.
